# Healthcare Claims Intelligence v3

مشروع Python لتصنيف استفسارات التأمين واستخراج الكيانات السريرية بالعربي والإنجليزي، مع محرك قواعد لمراجعة اكتمال المطالبات. كل سطر برمجي في ملفات Python معه تعليق عربي. ملفات البيانات الاصطناعية v0.2 مرفقة في `data/`.

| الملف | الوظيفة |
|---|---|
| `intent_model.py` | تصنيف الاستفسار إلى نية من ثماني نوايا باستخدام TF-IDF للمحارف وLogistic Regression |
| `ner_model.py` | استخراج التشخيص والإجراء باستخدام وسوم BIO، وتصحيح حدود المصطلحات المعروفة، ثم تحديد حالة التشخيص من السياق القريب |
| `claims_rules.py` | قواعد ثابتة تقرأ المرفقات والسياسة والموافقة وتعيد المستندات الناقصة وأسباب المراجعة |
| `training_data.py` | تحميل أمثلة التدريب الإضافية ومجموعة التقييم الجديدة |
| `evaluate_challenge.py` | تقييم النماذج على نصوص جديدة ومقارنة النتائج حسب اللغة |
| `common.py` | مسارات المشروع وقراءة CSV وJSON وJSONL |

## التشغيل في VS Code على ويندوز

فك الضغط، وافتح مجلد `healthcare_claims_code` في VS Code. من الطرفية داخله شغّلي الأوامر بالترتيب. استخدمي Python 3.10 أو أحدث.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 intent_model.py
.\.venv\Scripts\python.exe -X utf8 ner_model.py
.\.venv\Scripts\python.exe -X utf8 claims_rules.py
.\.venv\Scripts\python.exe -X utf8 evaluate_challenge.py
```

أول أمر ينشئ بيئة المشروع. ملفا النماذج يدرّبان على `train` ويطبعان نتائج `validation` و`test` ثم يحفظان الأوزان في `artifacts/`. أمر القواعد يختبر المطالبات الـ32.

## تجربة الاستدلال بعد التدريب

```powershell
.\.venv\Scripts\python.exe -X utf8 intent_model.py --text "ليش رفضتوا مطالبة العلاج الطبيعي؟"
.\.venv\Scripts\python.exe -X utf8 ner_model.py --text "التقييم اليوم أثبت السكري من النوع الثاني. الطبيب طلب تحليل السكر التراكمي للمراجعة القادمة."
.\.venv\Scripts\python.exe -X utf8 claims_rules.py --claim-id CLM-00001
```

على لينكس أو macOS استخدم `.venv/bin/python` بدل مسار Python الخاص بويندوز.

في NER، وسم `B` يعني بداية الكيان، و`I` يعني أنه مستمر، و`O` يعني أن الكلمة خارج الكيانات. `start` و`end` هما حدود الكيان في النص الأصلي، و`end` حصري. حالات التشخيص تشمل حاضر وسابق ومنفي ومشتبه به، وحالة الإجراء `ordered` ثابتة وفق تسميات v0.2.

## تحسين النماذج

- أُضيفت 96 رسالة سعودية و48 رسالة إنجليزية إلى تدريب النوايا. اختير إعداد انتظام Logistic Regression من نتائج قسم التحقق.
- أُضيفت 128 ملاحظة تدريبية لكل لغة من صيغ وسياقات مختلفة. يصحح NER حدود العبارة عندما يلتقط بدايتها ونوعها وتوجد في قاموس التدريب. يحلل مصنف الوجود والنفي والاشتباه والتاريخ السابق السياق القريب من التشخيص. في العربي يستفيد أيضًا من قرائن صريحة، مثل «ثبت» و«ما ثبت».
- مجموعة التقييم الإضافية تتضمن 32 رسالة و12 ملاحظة عربية و16 رسالة و8 ملاحظات إنجليزية. تحتوي على صيغ جديدة ومصطلحات جديدة وبعض الملاحظات متعددة التشخيصات. تُحمّل في أمر التقييم فقط.

## تصنيف النوايا في v3

أضافت v3 إلى تدريب v2 عدد 48 استفسارًا باللهجة السعودية، بواقع ستة أمثلة لكل نية. تستخدم بعض الأمثلة كلمات وخدمات متشابهة ليتعلم النموذج الفرق بين تغطية الخدمة وسريان التأمين والموافقة المسبقة وحالة المطالبة. يشغّل `evaluate_challenge.py` التقييم الإضافي ويطبع نتيجة `intent_probe.txt` أيضًا.
